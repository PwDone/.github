# PwDone organization profile

This repository holds the public organization profile for the `pwdone` GitHub
organization.

- `profile/README.md` is rendered at <https://github.com/pwdone>.
- `profile/assets/` contains the banner and icon used there.

To update the organization page, edit `profile/README.md` and push to the
default branch.

> The repository must be named `.github` under the organization for GitHub to
> use it as the organization profile.
